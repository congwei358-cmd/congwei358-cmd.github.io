贝贝橙广告助手隐私政策
更新日期：2026年10月22日
一、运营主体与适用范围
贝贝橙广告助手（Beibeicheng Ads Manager）由深圳市贝贝橙科技有限公司运营，仅供本公司内部管理自有亚马逊店铺的广告业务使用，不向其他卖家提供账户接入或广告代运营服务。
本政策说明本应用在通过 Amazon Ads API 访问已授权广告账户时，如何获取、使用、保护和删除相关数据。
二、获取的数据
在获得账户授权后，本应用根据所授予的权限及实际功能需要，获取以下信息：
- 广告账户标识、站点及相关配置信息。
- 广告活动、广告组、关键词、投放目标、预算、竞价及运行状态。
- 广告展示、点击、花费、归因订单、归因销售额等绩效报告。
- 为维持授权访问所需的访问令牌、刷新令牌，以及必要的操作和错误日志。
本应用不要求使用者向本应用提供亚马逊账户登录密码。
三、数据用途与广告操作
上述数据仅用于本公司自有店铺的广告报告查看、效果分析、费用监控和投放优化。
本应用可以根据本公司授权人员的操作或其配置的规则，通过 Amazon Ads API 调整广告预算、竞价、投放目标及广告运行状态。相关操作仅在已授权账户和权限范围内执行。
四、数据保护与披露
本公司采取合理的访问控制和凭证保护措施，将数据访问权限限制在履行相关工作职责所需的范围内。
本公司不出售或出租通过本应用获取的广告数据及授权凭据，不将其用于与本公司店铺广告管理无关的目的。执行授权的接口操作时，必要信息会传输至 Amazon。其他披露仅在取得适当授权，或适用法律要求的情况下进行。
如后续引入会接收相关数据的第三方服务，本公司将在使用前评估其数据处理方式，并相应更新本政策及取得必要授权。
五、数据保留、撤销授权与删除
本公司仅在实现上述用途所必要的期间保留相关数据，并遵守适用的法律及 Amazon 协议要求。
账户授权人员可通过 Amazon 提供的授权管理功能撤销本应用的访问权限，也可通过下方邮箱联系本公司停止接入或申请删除数据。
收到有效请求并完成必要核实后，本公司将在合理期限内停止相关访问，删除不再需要的数据和授权凭据；需要依法保留的信息仅用于相应保留目的。
六、政策更新与联系方式
应用功能或数据处理方式发生变化时，本公司会更新本政策，并在本页面标注更新日期。
